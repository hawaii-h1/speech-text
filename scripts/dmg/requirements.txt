# dmgbuild, which lays out the disk image window (package-release.sh). Build-time only:
# nothing of it ships in the app. Pinned by hash because the release job runs with the
# signing keychain unlocked. 1.6.7 is the floor, not a preference: up to 1.6.5 dmgbuild
# also wrote a `pBBk` bookmark beside the background's alias, and Finder on macOS 26
# follows that bookmark, fails to resolve it on the read-only image, and shows a white
# window. All three need Python 3.10 or later.
