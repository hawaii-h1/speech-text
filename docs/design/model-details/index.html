Model languages

A row never names a language on its own initiative. It says how many languages a model takes. It speaks about a language only if it is one of yours from Dictation › Languages I speak, and only when the model can't take it or is known to handle it badly. Switch the languages in the review bar: a Spanish speaker sees nothing about Ukrainian, and someone who listed no languages sees no warnings at all.

Languages I speak
The rules
  • Subtitle. Size (for local models) and the language count: “25 languages”, “English only”, “90+ languages”. Nothing when the vendor publishes no list (OpenAI) or when macOS decides (Apple).
  • “No Spanish” badge (warning kind, in words, not colour alone). The model's published list lacks one of your languages. One badge, naming the first such language, with “+1” for each further one.
  • A known weakness (“Makes mistakes in Ukrainian.”). These come from our own measurements and are stored on the model per language. The sentence joins the row's line only for someone who speaks that language.
  • Apple. The app asks macOS which of your languages work on-device on this Mac. The badge reads “No Ukrainian on-device”.
  • Unknown stays silent. A model whose language list is unpublished never warns. Nobody who listed no languages sees a badge.
  • Row lines name no language. They say what else the model is good at: speed, size, live text.
